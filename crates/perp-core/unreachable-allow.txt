# this list can only shrink, and a line removed is one real gap closed.
#
# What is left here that is not API surface:
#
#   local.rs    - `unload` and `estimate`. Warming, the VRAM lease and peer
#                 health are wired now (M-16, M-19, and M-31 for the lease);
#                 what is left is eviction, which stays out deliberately -
#                 evicting a model an operator loaded is a policy decision, not
#                 a mechanical one.
#   watchdog.rs - NoProgress, deliberately. It is L-11's first and blunter
#                 reading, counting only workspace changes, which punished a
#                 model for reading its own work - see MAX_QUIET_TURNS in
#                 agent.rs. Two rules for one requirement is worse than one, so
#                 this stays unwired rather than becoming a second opinion.
#   is_never / needs_approval / is_granted / close_cycle - the classifier and
#                 the per-cycle rule are used through pattern matching and the
#                 replay, not through these predicates. Real API surface.
