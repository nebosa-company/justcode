## Shape of the remaining work

The 105 open requirements are no longer evenly hard. Three observations that
should drive Phase C:

1. **The model layer is the only thing standing between this and a loop that
   runs itself.** Everything built so far is scaffolding for a step that calls a
   model, and no step does yet.
2. **`M-*` splits cleanly at the network boundary.** Roles, chains, privacy
   classes, model-fact parsing and the capability *decision* are pure logic,
   testable offline with recorded fixtures. Only the transport needs a socket.
3. **The transport hits the dependency policy head-on.** `http://` to LM Studio
   is reachable with `std::net::TcpStream`. `https://` to DeepSeek needs TLS,
   which needs a crate, which needs an approval under the binding. That is a
   Phase C decision, not a Phase D surprise.
