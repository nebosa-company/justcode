## The real surface, named

Process execution. Commands come from the binding, are split without a shell,
run with a declared environment and a deadline, and their process tree is killed
when that deadline passes. The classifier in `git.rs` refuses the destructive
half of git before spawning anything.

**That surface is about to grow.** Batches 6 and 7 add an HTTP client and API
keys. This pass is the last one where "no network, no secrets" is true, and the
next one should be read with that in mind.
